# 🎤 LearnRyme

**LearnRyme** is a fun and interactive app that helps you learn how to rhyme! Whether you're a budding poet, rapper, or just love wordplay — this tool makes rhyming simple and engaging.

## 🚀 Features

- 🧠 Learn the basics of rhyming
- 🎮 Interactive rhyme exercises
- 🔍 Word matching and suggestions
- 🌐 Built with modern web tech

## 🛠️ Getting Started

To run LearnRyme locally, follow these steps:

### 1. Clone the Repository

```bash
git clone https://github.com/Shiva-Bajpai/learn-ryme.git
cd learnryme
```
2. Install Dependencies
```bash
yarn install
```

4. Start the Development Server
```bash
yarn run dev
```
The app will be available at http://localhost:3000.
